# Как понять, где вы смотрите сайт

## Зелёная плашка «DEV: localhost»

При запуске `npm run dev` в правом нижнем углу появляется **зелёная плашка «DEV: localhost»**.

- **Плашка есть** → вы на localhost, изменения в файлах видны здесь
- **Плашки нет** → вы на Vercel/хостинге, изменения появятся только после `git push` и деплоя

---

## localhost — изменения не обновляются

**Причина:** браузер кэширует JS и CSS.

**Что делать:**
1. DevTools (F12) → Network → **Disable cache** → держать открытым
2. Или **Cmd+Shift+R** (жёсткое обновление)
3. Или `npm run dev:fresh` — очистка кэша и перезапуск

---

## Итого

| Где смотрите | Как увидеть изменения |
|--------------|----------------------|
| **localhost** (зелёная плашка) | Cmd+Shift+R или Disable cache в DevTools |
| **Vercel** (нет плашки) | `git push` → подождать 1–2 мин → обновить страницу |
