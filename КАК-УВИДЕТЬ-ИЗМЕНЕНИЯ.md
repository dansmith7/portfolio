# Как увидеть изменения

## Важно

**Я не запускаю сервер.** Я только редактирую файлы в папке проекта. Все изменения сразу сохраняются в файлы.

## Где вы смотрите сайт?

### 1. Localhost (npm run dev)

Если открываете `http://localhost:3000` или `http://localhost:3002`:

1. **Сделайте жёсткое обновление:** Cmd+Shift+R (Mac) или Ctrl+Shift+R (Windows)
2. Или откройте в режиме инкогнито
3. Или закройте все терминалы с `npm run dev`, запустите заново: `npm run dev`

### 2. Vercel / хостинг (your-site.vercel.app)

Сайт на хостинге показывает **старую версию** до деплоя!

Чтобы изменения появились:

1. Закоммитьте и запушьте в Git:
   ```bash
   git add -A
   git commit -m "Update"
   git push
   ```
2. Vercel автоматически задеплоит (обычно 1–2 минуты)
3. Обновите страницу на хостинге с Cmd+Shift+R

## Проверка

Кнопка "Download project presentation" теперь имеет **inline-стили** — чёрный фон и белый текст. Они применяются всегда, независимо от кэша CSS.
