# Локальная админка (без Supabase)

Все данные хранятся на твоём компьютере в папке **`server/data/`**:
- `site_settings.json` — настройки сайта
- `projects.json` — проекты (и медиа внутри каждого)
- `marquee_logos.json` — логотипы бегущей строки
- `uploads/` — загруженные файлы (фото, PDF и т.д.)

## Запуск

1. **В корне проекта создай или отредактируй `.env`:**
   ```
   ADMIN_PASSWORD=твой_пароль_для_входа_в_админку
   ```

2. **Установи зависимости (если ещё не ставил):**
   ```bash
   npm install
   ```

3. **В первом терминале запусти сервер данных:**
   ```bash
   npm run server
   ```
   Сервер будет на http://localhost:5006

4. **Во втором терминале запусти сайт:**
   ```bash
   npm run dev
   ```
   Сайт откроется на http://localhost:5005

5. **Админка:** http://localhost:5005/admin — войди паролем из `ADMIN_PASSWORD`.

Запросы с сайта к `/api` и `/uploads` проксируются на порт 5006 автоматически.
