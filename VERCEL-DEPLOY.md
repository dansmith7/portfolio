# Деплой на Vercel

## Пропала связь с админкой в деплое

Если на задеплоенном сайте нет данных из Supabase, админка «не связана», проекты не подгружаются:

1. **Vercel → ваш проект → Settings → Environment Variables**
   - Должны быть заданы **`VITE_SUPABASE_URL`** и **`VITE_SUPABASE_ANON_KEY`** (те же значения, что в локальном `.env`).
   - Проверьте, что переменные включены для окружения **Production** (и при необходимости Preview).

2. **Обязательно пересоберите проект после правки переменных:**
   - **Deployments** → у последнего деплоя **⋯** → **Redeploy** (галочку **Use existing Build Cache** снимите).

3. **Supabase:** если проект на бесплатном тарифе, проверьте в [supabase.com](https://supabase.com) → проект, что он не в статусе **Paused**. При долгом простое проект можно разморозить кнопкой **Restore**.

4. **Проверка:** откройте задеплоенный сайт → F12 → **Console**. Не должно быть сообщений вида `Supabase не подключен` или `VITE_SUPABASE_URL: ❌ отсутствует`. Во вкладке **Network** при загрузке главной или `/work` должны быть запросы к `*.supabase.co`.

---

## Почему не отображаются изменения из админки?

**Чаще всего:** на Vercel не заданы переменные окружения. Сайт не подключается к Supabase и показывает только fallback-данные (захардкоженные). Что бы вы ни меняли в админке — на публичном сайте это не появится.

---

## Что сделать

### 1. Добавить переменные в Vercel

1. Откройте [vercel.com](https://vercel.com) → ваш проект.
2. **Settings** → **Environment Variables**.
3. Добавьте:

| Name | Value |
|------|--------|
| `VITE_SUPABASE_URL` | `https://ваш-проект.supabase.co` |
| `VITE_SUPABASE_ANON_KEY` | anon public ключ из Supabase (Dashboard → Settings → API) |

4. **Save**.

### 2. Пересобрать и задеплоить

После добавления/изменения переменных **или изменения кода** нужно заново собрать проект:

- **Deployments** → у последнего деплоя **⋯** → **Redeploy** (галочку **Use existing Build Cache** лучше снять),  
  **или**
- Сделайте новый коммит и пуш в Git — Vercel задеплоит сам.

Без нового билда старые значения env (в т.ч. пустые) остаются в собранном приложении. **Новые фичи (например, кнопка Download presentation) появятся только после деплоя.**

## Дополнительно

- **Кэш:** после сохранения в админке кэш `siteData` очищается (`clearCache`), публичные страницы при следующем заходе/обновлении подтянут свежие данные из Supabase.
- **Проверка:** откройте сайт на Vercel → F12 → **Console**. Ошибок типа `Supabase не настроен` быть не должно. В **Network** при загрузке главной/проектов видны запросы к `*.supabase.co`.
